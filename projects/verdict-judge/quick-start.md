# 快速开始

1. 用 VS Code 打开一个工作区文件夹。
2. 在活动栏打开 **Verdict** 面板。
3. 创建比赛和题目，或打开已有的 `.verdict/` 工作区。
4. 将测试数据放到 `.verdict/data/<题目 id>/`，例如 `1.in` 和 `1.out`。
5. 在“测试点”页签扫描测试点，或使用“＋ 粘贴样例”录入内联样例。
6. 打开选手源码，点击顶部 **▶ 评测**；也可以在测试点行上单独运行。
7. 需要调试时点击 **🐞**，WA 时使用自动打开的 diff 查看首个不同位置。
8. 在“榜单”页签点击 **评测全部**，需要分享时导出 HTML 成绩单。

如果版本 `0.1.6` 出现“显示没有找到比赛配置”，先创建一个新比赛；仍然异常时重启 VS Code。当前仓库版本已更新到 `0.1.8`，遇到问题应优先查看项目更新日志。
