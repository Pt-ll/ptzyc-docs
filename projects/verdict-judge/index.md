# Verdict Judge

Verdict Judge 是一个 VS Code 扩展，把本地出题、数据管理、编译评测、调试、重测、榜单和成绩导出集成到编辑器中。

- 扩展显示名：`Verdict · VSCode 评测系统`
- 当前仓库版本：`0.1.8`
- 支持平台：Windows、macOS、Linux
- 支持语言：C++、Python（其他语言支持情况以扩展实际版本为准）
- 仓库：[Pt-ll/verdict-judge](https://github.com/Pt-ll/verdict-judge)
